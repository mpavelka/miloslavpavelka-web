How I work

Ship fast, safely

A short release cycle backed by solid test coverage, instead of manual testing, is what lets a company react when a new vulnerability appears.

Make quality visible

I want to know how a product really behaves. Thorough monitoring and a fast feedback loop show early whether what was shipped is good, and what to improve next.

Translate between worlds

I speak business, cyber security and software development, and I explain trade-offs clearly so the right decision can be made.

Design with the attacker in mind

Years of penetration testing, red teaming and bug bounty triage mean my designs are shaped by how systems are actually attacked.
